# Thymeleaf

Rendering server-side con Spring MVC. Controller pagine sottili, form object validati, Post/Redirect/Get, `th:text` per default, CSRF tramite `th:action`, testi in `messages*.properties`, test `@WebMvcTest` con Spring Security Test. Verificare la versione Thymeleaf gestita dal BOM Spring Boot prima di usare funzionalità specifiche. Vedi SB-009.
